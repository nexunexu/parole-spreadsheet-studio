# Parole Spreadsheet Studio

Bonjour. Construction d'un Outils Ultra Smart révolutionnaire qui remplace Excel. L'utilisateur crée un projet, et lorsqu'il arrive dans son espace de travail du projet créer il décris son calcul ou autres en langage naturel, il peut décrire tout ce qu'il veut  (tout ce qui est possible de faire sur Excel dans une cellule, toutes les formules et fonctions et autres, mais ici c'est en version langage naturel (tout ce qui peut être fait dans Excel, l'utilisateur pourra demander à l'outils. L'utilisateur décris ce qu'il veut en langage naturel, ensuite l'outils analyse la demande, puis l'outils exécute. L'utilisateur peut affiner sa demande encore et encore. Tout est possible dans ce nouveau tableur révolutionnaire qui fonctionne à 100% en langage naturel. L'outils est propulsé par GPT 6 Luna. L'outils est ergonomique avec une responsive qui fluidifie et optimise l'experience utilisateur.  L'utilisateur crée un compte pour accéder au dashboard (sans besoin de confirmation du compte par mail, sans besoin de connexion avec Google).  Lovable Cloud est connecté, avec la persistance des données de l'utilisateur en temps réel. Lovable AI est connecté, pour les fonctionnalités intelligentes du dashboard. Respecte exactement réellement le visuel de la capture d’écran qui affiche l'espace de travail d'un projet (couleurs exact, luminance colorimétrie exact,  icône, animations dynamiques visuels, et tout les autres éléments), je veux exactement ce qu’il y a sur la capture d’écran ci-joint, analyse les fonctionnalités qui seront fonctionnel dans notre outils.  Consigne obligatoire à suivre: Reste sur une implémentation simple, sans ajouter de bibliothèques lourdes, pour optimiser les performances et le coût de génération.
